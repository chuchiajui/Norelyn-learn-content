# Norelyn Learn Content

Norelyn Learn 的公開學習內容儲存庫，供教材、教學範例與知識文件的版本管理使用。

> **狀態：內容庫骨架。** 截至 2026-10-28，`main` 只有本 README；尚未加入可供發佈的課程或文章。建立儲存庫**不等於**已完成 Learn 的投稿、審核、同步或自動發布管線。

## 與 Learn 的關係

- **[Norelyn Learn](https://github.com/chuchiajui/Norelyn-learn)**：網站、學習路徑、API、使用者狀態，以及正在開發的個人 Agent／Knowledge 架構。
- **本儲存庫**：預留給**可公開**的內容原始檔與必要的版本歷史。
- Learn 現有內容可能仍位於網站程式碼或 D1。搬遷前應先決定內容的唯一權威來源與同步方向，避免同一篇教材產生互相衝突的版本。

## 發佈與隱私邊界

本儲存庫是 **Public**。請勿提交私人投稿草稿、未審核的作者內容、登入憑證、API Token、個人資料或未取得授權的教材。

投稿／審核是否使用其他私人儲存庫、D1 暫存或 GitHub 同步，應以 Learn 當前程式碼和已驗證的部署流程為準；本 README 不假設這些流程已經啟用。
